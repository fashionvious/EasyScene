# 测试剪辑提示词用例

> **生成日期**: 2026-06-03
> **测试目标**: 验证 AI 剪辑 Agent 的 Tool Calling 能力——Agent 能否根据自然语言指令正确调用已注册的工具。
> **适用模型**: 已接入 LangChain Agent 的 LLM (如 GPT-4o / Claude Opus)

---

## 1. 当前支持功能清单

以下能力由源码扫描确认，非外推猜测。

### 1.1 Agent 已注册的 22 个 Tools

源码: `jianying_agent.py:_create_tools()` → `registry.register_many(...)`

#### 基础工具 (8 个，handler 分散)

| Tool 名称 | 类别 | handler | 能力说明 |
|-----------|------|---------|---------|
| `resolve_media` | read | media_resolver | 将文件名解析为完整绝对路径，支持模糊匹配 |
| `list_media` | read | media_resolver | 列举所有可用的媒体素材文件 |
| `load_skill` | read | skill_parser | 加载技能描述文档到 Agent 上下文 |
| `list_cli_scripts` | read | cli_executor | 列出 10 个可用的 CLI 脚本 |
| `execute_cli_script` | compute | cli_executor | 执行 CLI 脚本 (见下方 1.2)，唯一的 async 工具 |
| `execute_jyproject_code` | write | python_executor | 执行 JyProject 编排代码，可调用 Python API (见下方 1.3) |
| `validate_jyproject_code` | read | python_executor | 验证 JyProject 代码语法，不实际执行 |
| `submit_storyboard` | write | storyboard_parser | 提交分镜 JSON，系统分步执行并显示进度 |

#### Phase 1 时间线编排 (3 个，handler: timeline_ops)

| Tool 名称 | 类别 | 能力说明 |
|-----------|------|---------|
| `apply_jcut` | write | J-Cut 声音先行 — 音频比视频先开始(audio_lead_us 提前量)，制造悬念感 |
| `apply_lcut` | write | L-Cut 画面先行 — 视频结束后音频尾部延长(audio_tail_us)，增强叙事流畅感 |
| `reorder_segments` | write | 片段重排 — 读取已有草稿 → 按 new_order 索引重建视频片段顺序 |

#### Phase 1 画面布局 (1 个，handler: layout_ops)

| Tool 名称 | 类别 | 能力说明 |
|-----------|------|---------|
| `apply_split_screen` | write | 分屏效果 — N 段视频同框播放，支持 2H/2V/2x2/3x3/1+2 五种模板 |

#### Phase 1 字幕与转场 (3 个)

| Tool 名称 | 类别 | handler | 能力说明 |
|-----------|------|---------|---------|
| `add_dual_subtitles` | write | subtitle_ops | 多语言字幕 — 双轨双语(primary+secondary)，时间严格对齐，仅支持 2 语 |
| `apply_zoom_transition` | write | transition_ops | 缩放转场 — seg1 尾部放大→seg2 头部缩小，连续缩放视觉流 |
| `apply_push_transition` | write | transition_ops | 推拉转场 — seg1 推出屏幕→seg2 推入屏幕，支持 left/right/up/down |

#### Phase 2 JSON 注入 (7 个，handler: draft_injector，直接操作 draft_content.json)

| Tool 名称 | 类别 | 能力说明 |
|-----------|------|---------|
| `inject_mask_transition` | write | 遮罩转场 — 为 segment 注入线性蒙版 KFTypeMaskCenterX 关键帧 |
| `inject_color_transition` | write | 颜色过渡转场 — 在 seg1/seg2 间插入纯色 segment 实现 A→纯色→B |
| `add_karaoke_subtitle` | write | 逐字高亮 — 每个字/词独立 TextSegment，颜色区分高亮态(>50 字自动降级为逐词) |
| `inject_subtitle_slide` | write | 字幕滑入 — 为 TextSegment 注入 transform_x/y 关键帧动画 |
| `apply_bgm_ducking` | write | BGM 闪避 — 为人声区间注入 BGM 轨道 KFTypeVolume 关键帧(duck_volume 0.2) |
| `apply_audio_speed` | write | 音频变速 — 为 AudioSegment 注入 speed 字段(0~10x)，自动偏移后续片段 |
| `apply_speed_ramp` | write | 曲线变速 — 注入 KFTypeSpeed 节点实现非均匀变速 |

### 1.2 通过 `execute_cli_script` 可调用的 10 个 CLI 脚本

| CLI 脚本 | 核心能力 | 关键参数 |
|----------|---------|---------|
| `asset_search` | 搜索特效/转场/动画/TTS发音人 | `query`(关键词), `category`(filters/transitions/text_animations等) |
| `auto_exporter` | 无头导出草稿为 MP4 | `draft_name`, `output_path`, `resolution`(480-8K), `framerate`(24-60) |
| `draft_inspector` | 列出/查看草稿详情 | `action`(list/summary/show), `name`, `limit` |
| `universal_tts` | 通用 TTS 语音生成(SAMI+Edge-TTS双后端) | `text`, `output`, `speaker` |
| `smart_rough_cut` | AI(Gemini)分析视频→高光粗剪 | `video` |
| `smart_zoomer` | 鼠标事件驱动的智能缩放 | `project_name`, `video`, `events_json` |
| `movie_commentary_builder` | 故事板 JSON→解说视频 | `--video`(必需), `--json`(必需), `--name`, `--bgm`, `--mask`(可选) |
| `web_recorder` | HTML/JS动画录制为视频 | `url`, `duration`, `output` |
| `sync_jy_assets` | 从剪映 App 同步 BGM | (无参数) |
| `api_validator` | 环境诊断(ffprobe/素材/草稿全流程) | (无参数) |

### 1.3 通过 `execute_jyproject_code` 可调用的核心 Python API

| API 方法 | 能力 |
|----------|------|
| `JyProject(project_name, overwrite=True)` | 创建/加载草稿 |
| `add_media_safe(media_path, start_time, duration, track_name, source_start)` | 导入视频/音频到时间线 |
| `add_audio_safe(media_path, start_time, duration, track_name)` | 导入纯音频 |
| `add_clip(media_path, source_start, duration, target_start, track_name)` | 从素材指定位置裁剪并放置到时间线 |
| `add_text_simple(text, start_time, duration, track_name, **kwargs)` | 添加文字(字体/颜色/背景/阴影/动画) |
| `add_narrated_subtitles(text, speaker, start_time, track_name)` | TTS配音+字幕时间轴自动对齐 |
| `add_tts_intelligent(text, speaker, start_time, track_name)` | 智能 TTS 语音生成 |
| `add_effect_simple(effect_name, start_time, duration, track_name)` | 添加视频场景特效(639+种) |
| `add_transition_simple(transition_name, segment, duration)` | 添加转场(437+种，支持中英文同义词) |
| `add_keyframe(property, time_offset, value)` | 添加缩放/位置/旋转/透明度/色彩/音量关键帧 |
| `add_fade(in_duration, out_duration)` | 音频淡入淡出 |
| `add_background_filling(fill_type, blur, color)` | 视频背景填充(模糊/纯色) |
| `add_cloud_media(query, start_time, duration, track_name)` | 搜索并导入云端素材 |
| `add_cloud_music(query, start_time, duration, name)` | 搜索并导入云端 BGM |
| `save()` | 保存草稿并触发后处理管线 |
| `get_track_duration(track_name)` | 获取轨道当前时长(用于自动追加) |

> **注意**: 上表仅供 `execute_jyproject_code` 内部使用。日常高频操作 (J-Cut / 分屏 / 双语字幕 / 转场 / 片段重排 / BGM 闪避) 已有独立注册的 Agent Tool，见 1.1 节 Phase 1-2 部分，应优先使用独立工具而非手写代码。

| `apply_split_screen` | `project_name`, `video_paths`(路径列表) | `template`(2H/2V/2x2/3x3/1+2), `duration`, `fill_mode`(loop/freeze/stretch) |

| `apply_push_transition` | `project_name`, `video_path_1`, `video_path_2` | `direction`(left/right/up/down), `ramp_duration_us` |
| `inject_mask_transition` | `project_name`, `segment_id` | `direction`(left_to_right/…), `feather`(0~1) |
| `inject_color_transition` | `project_name`, `seg1_id`, `seg2_id` | `color`(#RRGGBB), `duration_us`(默认0.5s) |

| `apply_bgm_ducking` | `project_name`, `voice_segments`(dict 列表) | `bgm_track_name`(默认"BGM"), `duck_volume`(默认0.2), `fade_us` |
| `apply_audio_speed` | `project_name`, `track_name`, `segment_index`, `speed` | — (speed 范围 0~10) |
| `apply_speed_ramp` | `project_name`, `segment_id`, `speed_curve`(dict 列表) | — (每个点: target_time_us + speed) |

## 2. 测试用例集

### 2.1 P0 — 原子功能测试 (单工具直接调用)

| **预期行为** | Agent 调用 `resolve_media("test_video_01.mp4")`，返回完整绝对路径。不会先调用 `list_media` 浪费时间。 |

#### P0-02: 素材列表浏览

|------|------|

### 2.2 P1 — 复合逻辑测试 (多步编排)

#### P1-01: 多素材拼接 + 转场 + BGM

| 字段 | 内容 |
|------|------|
| **测试场景** | 短剧混剪：导入多段素材、自动拼接、在片段间添加叠化转场、铺 BGM |
| **用户提示词** | "我有一段旅行视频 travel_main.mp4。帮我把其中 0-5 秒、10-20 秒、30-40 秒这三段高潮部分裁剪出来，拼接成一个连播视频。片段之间用'叠化'转场过渡，最后铺一个轻快的 BGM，整体时长控制在 20 秒左右" |
| **预期行为** | Agent 应通过 `execute_jyproject_code` 生成多步代码: ① 对 3 个片段分别调用 `add_clip(path, source_start, duration)` 依次导入 ② 在片段衔接处调用 `add_transition_simple("叠化", seg, "1s")` ③ 调用 `add_cloud_music("轻快", "0s", "20s", "BGM", track_name="BGM")` ④ `save()`。 |

#### P1-02: J-Cut 开场 + 旁白配音 + 字幕

| 字段 | 内容 |
